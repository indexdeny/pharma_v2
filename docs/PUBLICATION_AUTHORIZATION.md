# Publication authority

On 2026-11-18 the owner explicitly authorised public publication of PharmaGen PRO code, catalogue data, documentation and owned/authorised results, asserting ownership or authority. This supersedes the former internal-publication restriction. It does not select an open-source licence or grant blanket reuse permission for third-party trademarks.

The owner subsequently attested that historical Gemini and FAL credentials were revoked, that potentially affected browser sessions were reviewed/ended, and that existing author/committer/tagger identity may remain public. These are owner statements; provider accounts were not independently validated.

Credentials, session values, personal home paths, private recovery artifacts and unapproved third-party materials are excluded. Remote non-fast-forward replacements and existing-tag changes still require separate approval of the exact ref map.
