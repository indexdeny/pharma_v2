# Cleanup policy

5,031 original dev paths were excluded from the working index while retained privately. This does not by itself shrink Git history. The separately prepared history cleanup removes historical archives, generated outputs/state/logs, browser diagnostics, machine tooling and unreviewed bulk photographs/model weights. Detailed path/commit impact and recovery inventories remain private.

Required runtime modules, entry points, schemas, declared dependencies, catalogue inputs and all 391 JSON passports are preserved. The privacy change derives home paths per user; no image-generation algorithm was replaced.

Only the reviewed historical generic preview is included as an image demonstration. Original photos with unconfirmed manufacturer marks and external pretrained weights are not redistributed. [Evidence](docs/portfolio-evidence.md); [security](FINAL_SECURITY_AUDIT.md).
